# Floreios e Borrões

Floreios e Borrões é uma livraria no Lado Norte, Beco Diagonal. Estabelecido em 1454, é onde a maioria dos alunos de Hogwarts adquire seus livros escolares.

* Autor: Jeferson Braga
* Data: 08 março 2025.

## Clonar ativade

No terminal clone o repositório da atividade 4.
```sh
git clone -b Atividade_4 https://github.com/JefersonBLuz/MaisPraTi.git
```

Apos clona acesse a pasta 'MaisPraTi' e inicializa 'index'

### API

Neste projeto foi utilizado 1 API de consulta.

* [dummyjson](dummyjson.com)

Api para recolher os comentários.

### Bibliotecas utilizadas

Neste foi utilizado diveras bibliotecas:

1. AOS CSS
    * Estilização nos comentários
2. Swiper JS
    * Estilização e configuração para o carrossel de imagens
3. EmailJS
    * Biblioteca responsável para enviar email para contatos.
4. Tailwnd CSS
    * Biblioteca responsável pela estilização da página.
